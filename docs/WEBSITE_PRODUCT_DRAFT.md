## English

PDF Page Duplicator

Repeat each PDF page two or four times on one sheet.

Choose Portrait or Landscape, check the layout diagram and create a new PDF.
Right-click a PDF in File Explorer to open it directly in Page Duplicator.
Follow the progress percentage and get confirmation when the file is saved.

Processing stays on your computer. Your original PDF stays unchanged. Copies
scale proportionally, keeping the original paper's physical dimensions in the
selected orientation. Each source page produces one output page.

Windows 10 22H2 or later and Windows 11, x64. Runtime included.

Preview diagrams show paper proportions and placement, not PDF content.
Rotated/cropped pages and non-default page origins are currently unsupported.
Interactive links, annotations and forms are not guaranteed to be preserved.
The source folder must be writable. One PDF per Explorer action.

## Tiếng Việt

PDF Page Duplicator

Lặp mỗi trang PDF thành hai hoặc bốn bản trên một tờ.

Chọn giấy dọc hoặc ngang, kiểm tra sơ đồ bố cục rồi tạo PDF mới. Nhấp phải vào
file PDF trong File Explorer và chọn Page Duplicator để mở sẵn file đó.
Theo dõi phần trăm tiến trình và nhận thông báo khi file được lưu thành công.

PDF được xử lý ngay trên máy tính. File gốc được giữ nguyên. Các bản sao được
thu phóng đúng tỷ lệ, giữ kích thước giấy gốc theo hướng đã chọn. Mỗi trang
nguồn tạo ra một trang đầu ra.

Dành cho Windows 10 22H2 trở lên và Windows 11, x64. Có sẵn runtime đi kèm.

Sơ đồ chỉ thể hiện tỷ lệ giấy và vị trí bản sao, không hiển thị nội dung PDF.
Chưa hỗ trợ trang xoay, trang cắt hoặc tọa độ gốc trang khác mặc định. Không
cam kết giữ liên kết tương tác, chú thích và biểu mẫu. Cần quyền ghi vào thư
mục file nguồn; menu Explorer mở một PDF mỗi lần.
